# 사업공고·시연 도구·백업 수정 후 점검

2026-09-08 로컬 소스 기준. 자동 검증에서 16개 화면·단계를 4개 역할(로그인 전, 지원기업, 충남TP, 관리자)로 열어 오류 없이 렌더링되는지 검사했다. 공통 저장 안내 버튼과 소스 다운로드 연결, 시연 도구가 업무 헤더 앞에 배치되는 구조 및 현재 화면 SFR의 표시 위치도 각 조합에서 검사했다.

| 페이지 | 기능 점검 |
|---|---|
| 공고 / 메인 | 접수기간·마감 표시, 상세 항목, 팝업 드래그·키보드 이동·화면 범위 제한, 텍스트 첨부 다운로드, 관리자 수정·신규 등록·행 추가/삭제, 로그인 역할 전환, FAQ 검색 이동, 메인 노출 설정 반영 |
| 기술닥터 통합검색 | 검색조건, 비교 선택, 등록, JSON으로 검색조건·비교 선택 복원 |
| 기술닥터 상세 | 정보 표시, 소관 기관 수정, 타지역 수정 제한, 변경이력 |
| 매칭·지원 관리 | 역할별 목록; 업무규칙 검사에서 요청 중복·지역 권한·처리 순서 확인 |
| 통계·성과 | 기간 오류 및 지역 필터, 역할별 접근 화면 |
| 사업 선택 | 사업 목록의 접수기간·마감, 신청서 열기, 신청서 문맥 유지 |
| 신청기업 정보 | 저장, 필수값 검사, 주소 증빙 재확인, 제출완료 수정 제한 |
| 접수서류 확인 | 동의, 일괄조회, 불일치 선택, 재조회, 첨부, 제출·기관 보완요청 |
| 제출 및 보완 | 미완료 제출 차단, 제출 완료, 보완 후 재제출 |
| FAQ / 소통하기 | 검색과 역할별 화면, 업무분류 및 공개 조건 |
| 표준분류 관리 | 관리자 저장, 변경사항 보존, 기타 역할 화면 |
| 메인·소통 설정 | 노출 변경의 메인 반영, 기타 역할 화면 |
| 연계서류 설정 | 관리자 설정 화면, 업무규칙 검사에서 중지 서류의 일괄조회 차단 |
| 시연 안내 / SFR 레이어 | SFR 15개 정의·세부내용 전부 대조, 화면 전환 없이 레이어 열기, 입력값 유지, 배경 화면 저장, 이동·가로/세로 크기 조절·키보드 조작·작은 화면 범위 제한 |

SFR 15개 전체에 대해 디자인·화면·기술·데이터·실서비스 구현 계획이 표 우측 셀과 레이어에 표시되는지 검사한다. 모든 메뉴 링크를 4개 역할로 실행하여 공개·허용 화면은 직접 이동하고 나머지는 허용 역할만 선택하는 로그인 팝업 후 목적지로 이동하는지 검증한다. 로그인 취소 시 화면·역할·미저장 입력값 유지, 잘못된 역할 선택 차단, 취소한 목적지가 이후 로그인에 남지 않는 동작도 포함한다. JSON으로 식별자가 변경된 전문가·신청서를 동적으로 선택하며, 빈 목록에서도 데이터를 임의 생성하지 않는다. 레이어 기본 너비 900px 및 320·375·740px 화면 범위 제한은 DOM 모의 환경에서 검사한다.

백업은 기존 키 이관, 다른 앱 데이터 보존, 독립된 PC 저장소 간 전체 데이터·처리이력 복원, 역할·화면·검색조건·비교 선택 복원, 예전 JSON 호환, 잘못된 파일의 적용 차단을 검사한다. 저장 창의 정상 쓰기·취소·쓰기 실패·차단 후 대체 다운로드는 모의 API로 검사한다.

JSON 불러오기는 가져온 파일에 없는 기존 PC의 게시글·FAQ·신청정보·설정·이력이 남지 않는지 추가 검사한다. 파일에 들어 있는 전체 상태로 교체하며, 파일의 빈 목록도 그대로 적용한다.

공고는 상세항목이 없는 구버전 자료의 자동 보완, 빈 목록 유지, 권한·날짜·금액·첨부 검증, 저장 실패 시 원상 보존을 검사한다. 독립 저장소 간 내보내기·가져오기로 본문·지원프로그램·담당자·텍스트 첨부 바이트가 함께 복원되는지 검사한다. 모바일 스타일은 최소 너비 해제, 줄바꿈, 표 가로 스크롤 및 팝업 내부 세로 스크롤 규칙을 검토했다.

소스 ZIP은 전체 Git 파일 목록과 바이트 일치, 압축 무결성, 제외 폴더 미포함, 재생성 시 동일 결과, 실제 로컬 HTTP 200 응답과 다운로드 바이트 일치를 검사한다. 임시 저장소에서 업로드 스크립트의 커밋·로컬 원격 push를 실행하며 Git 줄바꿈 변환, 변경 없는 재실행, 스테이징하지 않은 파일의 배제, 소스 변경 후 오래된 ZIP 검증 실패까지 확인한다. 실제 GitHub push나 Render 배포는 이 점검에서 실행하지 않는다.

검증 명령은 `tests/README.md`에 있다. 연결된 실제 브라우저가 없어 실제 파일 저장 창, 마우스·키보드 조작, 화면 배치의 시각적 검사는 수행하지 못했다. 자동 테스트 통과는 실서비스 인증·DB·기관 연계 검증을 의미하지 않는다.
