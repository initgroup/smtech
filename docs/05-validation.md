# 검증 결과와 남은 확인사항

검증일: 2026-09-08. 가상 데이터·로컬 파일·현행 공개 리소스 기준이다.

node tools/package_handoff.cjs
node --test tests/core.test.cjs tests/dom.test.cjs tests/static.test.cjs

DOM 테스트는 linkedom과 최소 브라우저 API 보완을 사용했다. 실제 브라우저 엔진의 레이아웃·스타일·포커스·파일선택창을 시험한 것으로 간주하지 않는다.

추가 확인:

- 로컬 Python 서버가 `http://127.0.0.1:8080/region/rms/`에 HTTP 200 응답함을 확인했다.
- 인앱 브라우저에서 시연 페이지 제목이 정상 표시되는 것을 확인하고 시연 탭을 유지했다.
- 선택적 읽기 전용 WebMCP `rms_search_demo_doctors`가 등록됨을 확인했다. `{query:'소재',region:'충남'}`은 가상 전문가 목록을 반환했고, 숫자 query는 의도한 검증 오류로 거절됐다. 이 도구는 데이터나 실제 사이트를 변경하지 않는다.
- 공개 소스 원본 91개와 복사한 공통 CSS/이미지/폰트의 SHA-256을 재검증했다.
- 원본 HWP/PDF와 수집 원본은 수정하지 않았다.

## 검증 과정에서 수정한 결함

- 제출완료 신청서의 재조회·동의철회·임시저장으로 제출 잠금이 풀리는 문제.
- 서류 상태만 ‘제출완료’로 바꾼 JSON을 근거 없이 수용하는 문제.
- 이전 주소 조회결과로 기관의 새 보완요청을 완료 처리하는 문제.
- 업무유형의 사용/노출 해제가 메인 질문에 반영되지 않는 문제.
- JSON의 사용자/분류 종류/지원지역 참조 검증 부족.
- 신규 등록 폼의 빈 ID가 생성 ID를 덮어써 저장되지 않는 문제.

현재 테스트에 해당 회귀 사례를 포함했다. `tests/review-core-*`는 수정 전 발견 기록이며 현재 결과표로 사용하지 않는다.

## 고객·내부 개발자와 확정할 사항

1. 기술닥터 등록기관 권한과 총괄관리자 예외권한, 초광역권 요청 처리기관·승인 절차.
2. 표준분류 공식 코드와 기존 전문가 데이터 매핑, 현행화 주기, 통계의 지역/기간/완료 정의.
3. 실제 서비스 Java/WAS/프레임워크·JSP include 구조. HWP에 개발·운영 버전이 다르게 기재되어 있음.
4. 실제 지원 브라우저와 공통 JS 함수·요청/응답 구조. 경로명만으로 버전을 추정하지 않음.
5. 서류별 실제 제공기관/규격·식별자, 동의 문구·보유기간·철회, 만료기준, 재사용 및 재동의 범위.
6. 기관 보완요청 시 조회로 해결 가능한 사유와 직접 첨부가 필요한 사유, 제출 후 수정/철회 정책.
7. 파일 용량/형식/암호화·바이러스검사·저장/다운로드, 접수서류와 결과보고 첨부 정책 구분.
8. FAQ 관련검색 기준, 공개 개인정보 제거, 분류 매핑/메인 노출 권한, 실제 이용빈도에 따른 배치.
9. PDF의 원/천원, 20분/60분, 일부 설명 오기 등 실제 운영값.
10. RFP 총괄 70건/상세71건 및 중복 COR-02 정리 방식.

선행개발 결과는 화면과 업무 동작에 대한 고객 합의를 앞당기는 용도다. 위 미검증 항목은 운영 납품 시 필요한 실제 연동·검증으로 남는다.
