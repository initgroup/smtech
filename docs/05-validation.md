업무 HTML·CSS·JS에 시연 도구·SFR·가상 저장소가 섞이면 패키징을 중단합니다. ZIP 파일 목록과 SHA-256·CRC도 생성 시 검증합니다. 동일 소스 재패키징의 바이트 일치와 과거 버전 보존은 임시 테스트 디렉터리에서 검증했습니다. 실제 프로젝트의 Git commit/push는 실행하지 않았습니다.

DOM 검사는 Node + linkedom의 이벤트 시뮬레이션입니다. 실제 브라우저의 픽셀·글꼴·레이아웃·스크린리더 검수를 대신하지 않습니다. Java/JSP/WAS 컴파일, 내부 인증/DB/API, 실제 기관 통신·동의 정책·첨부 저장은 내부 연계 후 검증해야 합니다. 업무용 진입점은 서버 bootstrap 연결을 요구하며 시연 데이터로 자동 대체하지 않습니다.
