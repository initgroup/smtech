# 2026-10-15 Q&A 및 요구사항 추적 변경

## 사용 방법

1. `start.ps1`로 시연을 시작하고 `http://127.0.0.1:8080/region/rms/`에 접속합니다. 실행 정책이 제한된 PC에서는 시스템 정책을 바꾸지 않고 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1`로 이 프로젝트 스크립트만 실행할 수 있습니다.
2. 시안 1·2·3을 선택한 뒤 메인의 Q&A에서 글쓰기·수정·삭제·댓글·답변을 확인합니다. 로그인 전 비회원은 작성 시 지정한 비밀번호로 본인을 확인합니다. 로그인 후에는 작성자 또는 관리자가 수정·삭제합니다.
3. 비공개 회원 글은 본인에게 표시됩니다. 비회원은 글번호·비밀번호 확인 메뉴로 다시 열 수 있습니다. 공개 목록과 메인에는 비공개 글이 표시되지 않습니다.
4. Quill 편집기에서 굵게·기울임·제목·목록·인용·코드 서식을 사용할 수 있습니다. 개인정보 검사·미리보기에서 마스킹한 내용을 확인하고 저장합니다. 이미지·파일 첨부는 제공하지 않습니다.
5. 메인 Q&A의 최근 질문/답변완료 선택 및 관리자 메인 노출 설정을 확인합니다. 개인정보를 탐지한 게시물은 메인 노출을 차단합니다.
6. SFR 버튼에서 각 세부항목의 번호·구현상태·위치·후속 범위를 확인합니다. 요구사항 상세에서 구현 위치로 이동할 수 있으며, 기본 미리보기에는 설명 상자를 삽입하지 않습니다.
7. SFR-09 오른쪽의 보라색 개인정보 보호 영역에서 공식 PDF 3개, 기술 설명, JS 소스를 내려받습니다. Q&A의 보라색 밑줄 `김○○`·`010-****-****`를 클릭하면 기술 설명 레이어가 열립니다.

## 변경 범위

전체 15개 SFR, 원문 세부항목 93개를 개별 관리합니다. SFR-09는 SFR-09-01부터 SFR-09-07까지 원문 순서로 등록했습니다. 시연 구현·부분 구현·후속 구현을 구별하며 기존의 미구현 서버·기관 연계를 완료로 바꾸지 않았습니다.

업무 배포 ZIP에는 Q&A·에디터·마스킹 로직·계약·공식 참고자료를 반영합니다. 요구사항 매핑은 `docs/requirements-implementation.json`에 포함하며, 시연 전용 레이어는 기존 분리 정책에 따라 업무 런타임에서 제외합니다. 시안별 ZIP은 동일 HTML·JS를 공유하고 선택 CSS만 다릅니다. 원문 `prototype/region/rms/`는 이식 ZIP에서 `web/` 경로에 해당합니다.

## 개인정보 보호 증거와 한계

세부 근거·패턴·예시·오픈소스 비교는 [개인정보 보호 기술 설명](09-privacy-protection.md)에 정리했습니다. Quill은 편집, DOMPurify는 XSS 정화, 자체 RMSPrivacy는 개인정보 탐지·마스킹을 담당합니다. 다운로드한 공식 문서의 수집일·원본 주소·해시는 `reference/privacy/provenance.json`에 있습니다.

기능 검증에는 회원/비회원 권한, 비공개 글 확인, 댓글·답변, 메인 노출 차단, 원문 비저장, 태그로 나눈 번호, 유니코드·제로폭 문자·이메일 엔티티, 실제 Quill/DOMPurify 번들을 포함했습니다. 3개 시안의 공통 Q&A 경로와 요구사항 표시도 DOM 검사했습니다. 공식 PDF는 HTTP 다운로드 바이트와 원본 SHA-256을 비교했습니다.

연결된 브라우저가 없어 실제 브라우저 시각검수는 수행하지 못했습니다. jsdom/linkedom 검증은 실제 브라우저 렌더링·접근성 장비 검수를 대체하지 않습니다. 운영 서버·DB·기관 인증 연동도 이 저장소에 없으므로 적용 완료로 표기하지 않습니다. 서버 정책 예제는 이관용이며 실제 HTTP 인증·CSRF·권한·트랜잭션과 연결해야 합니다.

## 최종 검증 결과

- Node 기능·DOM·실제 라이브러리 검사: 130개 통과, 실패·건너뜀 0개.
- Python 패키징·Git 자동화·서비스 수명주기 검사: 23개 통과.
- 공식 PDF 3개의 다운로드 바이트와 SHA-256 일치, 모든 신규 화면 자산 HTTP 200 확인.
- 시작·종료·재시작 스크립트를 다른 작업 폴더에서 호출해 확인. 관리자 프로세스 조회 대신 웹 공개 루트 밖의 일회성 토큰으로 해당 로컬 서버만 종료합니다. 잘못된 토큰은 거절합니다.
- 시안별 ZIP은 패키징 단계에서 CRC·목록·각 파일 해시와 공통 소스 일치를 검증합니다.

## 전체 화면의 SFR 표시 범위

실제 업무 화면·입력 폼·목록·상세 팝업·마스킹 툴팁에는 SFR 번호·요구사항 설명·구현상태·기능 강조 표시를 넣지 않습니다. 전 화면에 주석을 주입하던 feature-trace 런타임을 제거했습니다. 마스킹 값과 기술 도움말은 유지하고, SFR 확인은 상단 시연 도구 또는 전용 요구사항 화면·레이어에서 수행합니다.

## 다양한 문서 기반 개인정보 예시

시안 1·2·3의 공개 Q&A에 16개의 서로 다른 합성 문의글을 반영했다. 이름·전화번호 외에 안내서 주요 8종과 주소·생년월일·교육·건강·가족·고용·소득·계정·접속 IP·위치정보까지 20개 항목을 제목·본문·댓글·답변에 분산했다. 공개 화면에는 실제 필터를 거친 값만 배포하며 마스킹 부분 클릭 시 항목별 설명과 PDF 근거 쪽수가 열린다. 실제 업무 영역의 SFR 미표시는 유지한다.
